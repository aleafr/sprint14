# Sprint 14 — Projeto Final de Data Analytics

Projeto final desenvolvido durante o bootcamp de Data Analytics da TripleTen.

## Objetivo

Aplicar, de forma integrada, os conhecimentos adquiridos ao longo do curso em um projeto completo de análise de dados, utilizando técnicas de exploração, tratamento, visualização e interpretação de dados.

## Descrição

Neste projeto final foram reunidas diferentes habilidades desenvolvidas durante o bootcamp, incluindo:

- limpeza e preparação de dados;
- análise exploratória;
- visualização de dados;
- análise estatística;
- identificação de padrões e insights;
- construção de conclusões e recomendações baseadas em dados.

O projeto foi desenvolvido em Jupyter Notebook e complementado por uma apresentação final com os principais resultados obtidos.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Tableau Public

## Etapas do projeto

1. Carregamento dos dados  
2. Pré-processamento e limpeza  
3. Análise exploratória  
4. Visualização dos dados  
5. Análises estatísticas  
6. Interpretação dos resultados  
7. Conclusões e recomendações finais

## Resultados

A análise permitiu identificar insights relevantes e responder às perguntas de negócio propostas no projeto, utilizando dados reais e técnicas aprendidas ao longo do curso.

## Arquivos do projeto

- Notebook `.ipynb`
- Apresentação final `.pdf`
- Dashboard/Tableau Public (quando aplicável)
